# GS4XP update files

This repository is used by GS4XP's built-in updater: `gs4xp-update.json` (signed) says which version is current, and the
releases hold the update packages it downloads. **To install GS4XP, use the installers at
[GS4XP/NumidiaGSE](https://github.com/GS4XP/NumidiaGSE/releases/latest).**
